# 微信图片顺序发送助手

Windows 桌面程序：选择图片文件夹和好友／群聊，按 **图片 → 确认上传完成 → 图片名称** 逐张发送。

**使用前请将电脑微信更新到官方最新版本：[微信官方下载](https://pc.weixin.qq.com/)。本版本适配 Windows 微信 4.1.15，具体已验证构建为 4.1.15.53。** 如果微信已升级到更高版本，请同时更新发送助手。程序界面会持续提醒，并自动检测版本。

## 下载安装

在 [Releases](https://github.com/JupiterLXV/WeChatImageSender/releases) 下载 Windows 压缩包，完整解压后运行 `WeChatImageSender.exe`。保留同目录的 `_internal` 文件夹，无需安装 Python。

1. 更新并登录电脑微信。
2. 阅读界面内的辅助功能说明，按需勾选“允许临时启用微信辅助功能”。默认不启用，同意仅对本次助手运行有效。
3. 选择图片文件夹，核对发送顺序和实际要发送的名称。
4. 点击“刷新最近会话”，选择目标，再点击“使用所选会话”；也可以先在微信打开目标好友／群聊，再点击“使用微信当前聊天”。核对显示的接收对象。
5. 选择与微信设置一致的发送快捷键：Enter 或 Ctrl+Enter。
6. 点击“开始 / 继续”。期间保持微信在前台，不切换聊天、编辑草稿或滚动消息列表，也不要从其他设备同时发送。
7. **F8** 可停止。停止不会撤回已提交消息，微信可能仍在继续上传。

演示模式只模拟队列，不连接微信：运行 `WeChatImageSender.exe --demo`，或源码目录的 `演示模式.cmd`。

## 如何确认图片已发送

不会把快捷键成功、缩略图出现、输入框清空或固定延时当作发送完成。程序锁定本次唯一新增的图片消息，持续核对聊天及消息标识，并检查：

- 微信公开的明确发送／失败状态；4.1.15.53 的图片控件通常不提供明确状态文字。
- 对已验证的 4.1.15.53，核对右侧缩略图与源图片一致，检测该图片旁的上传指示。若观察到本条图片上传，再确认指示消失且稳定至少 1.5 秒，才放行文件名。
- 如果上传太快，没捕捉到转圈，则还会只读检查这张图片的菜单：核对“复制、编辑、收藏、引用、另存为、用窗口打开”等完成后操作均可用，且缩略图匹配、上传区域清空，再等待状态稳定。程序只打开并关闭菜单，不执行菜单项。测试中上传期间的菜单仅提供转发、多选、用窗口打开和删除，不满足完成条件。
- 失败标记、未知状态、图片不匹配、消息被替换／不可见、切换聊天或失去前台时暂停。不会因消息消失而认定成功，也不会自动重发结果不明的消息。

名称提交后，核对本次新增文字与文件名完全一致，再进入下一张。确认的是**微信客户端显示的发送状态**，不等于对方已读、已下载或接收端最终回执。

## 辅助功能说明

微信 4.1.15 默认可能不公开聊天控件。获得本次运行的同意后，程序校验运行模块 `Weixin.dll` 的完整 SHA-256，仅对已验证的 4.1.15.53 构建临时修改 **1 个 Qt 辅助功能标记字节**，并记录原值；未知指纹拒绝修改。

此操作可能使微信不稳定。正常退出助手时尝试恢复；如果助手异常终止或恢复失败，重启微信可恢复临时状态。不修改安装文件，不访问聊天数据库，不读取聊天密钥或登录凭据。

鼠标操作会先核对点击位置属于微信；仅在必要时短暂调整微信渲染窗口的点击穿透样式，并随即恢复样式。

## 状态不明时与历史恢复

点击“处理待核实项”，到微信逐条确认实际状态：

- 图片已成功而名称未提交：选择“图片已成功，仅补发名称”。
- 名称实际上已发出：选择“文件名已成功，标记本张完成”。
- 确认本条没发出、也没有仍在上传的内容：清理草稿后才选择重试。
- 仍不确定：保持暂停。

操作前先写入记录，结果不明时不会自动重复发送。“恢复历史任务”仅支持**同一次微信进程／登录会话中的原聊天**。可以重启助手；微信重启、重新登录或换号后，需核实旧记录并为剩余文件新建任务。4.x 无障碍接口不提供可靠账号 ID，程序不会仅凭昵称认定是同一账号。旧 3.x 任务不能直接接续到 4.x。

## 图片、排序与记录

- 支持 JPG/JPEG、PNG、BMP、WEBP、TIFF、静态 GIF；动图、多页图片需先转成静态单张。
- JPG 中的 MPO 多图数据只取主图；这是将照片作为单张静态图片发送，不是拆分其内部所有图片。
- 自然排序：`1.png`、`2.png`、`10.png`；可包含子文件夹，可选名称是否含扩展名。
- 以静态图片粘贴，按 EXIF 调整方向，透明区域转白色；微信可能压缩，不保证原文件字节一致。
- 不修改源图片，读取时及发送前核对 SHA-256；发送期间占用系统剪贴板。
- 进度位于 `%LOCALAPPDATA%\WeChatImageSender\jobs`，包含所选路径、摘要、聊天名称、发送阶段和人工决定，不保存完整聊天记录。
- 应用中的状态截图仅在内存处理；开发诊断文件保存在本机 `data/`，不会上传到源码仓库。

## 从源码运行

Windows 10/11，64 位 Python 3.10～3.12：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

也可以双击 `安装依赖.cmd`，完成后双击 `启动程序.cmd`。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe main.py --demo
.\.venv\Scripts\python.exe main.py --diagnose
```

`--diagnose` 只读检测版本和窗口，不启用辅助功能、不发送消息。打包版支持 `--diagnose --diagnose-output diagnostic.json`。

打包：

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

`tools/` 中的实发验证脚本仅限开发，必须先取得明确的单次测试授权；日常使用无需运行。源码不包含本机聊天截图、进度记录、凭据、虚拟环境或旧二进制。
