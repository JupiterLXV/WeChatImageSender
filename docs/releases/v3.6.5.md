# WeChatImageSender v3.6.5

保持现有界面与 wcs 参考版发送流程，减少重复识别计算和长队列进度更新造成的等待。

- 缓存识别模板，画面未变时使用局部定位；画面或窗口尺寸变化后重新匹配。
- 转圈和失败状态仍逐帧检查，保留至少 1.5 秒连续稳定确认、名称提交前复查及 F8 暂停。
- 补齐 125%/200% 常见缩略图尺寸，修复合成回归中因图片拟合偏差漏判中央转圈的问题。
- 减少大队列的重复统计和界面刷新；同张图片不再反复解码。
- 仅对粘贴前的剪贴板占用自动重试一次，提交状态不明时继续人工核实，避免重复发图。
- 每张结束或暂停后生成仅含时间、序号与状态的性能记录，便于定位不同电脑上的卡顿。默认位置为 `%LOCALAPPDATA%\WeChatImageSender\performance`，程序日志会显示本轮文件位置。

完整解压 Windows x64 ZIP，运行其中的 `WeChatImageSender.exe`，无需安装 Python。旧版本与历史任务可保留；尚待核实的条目请先检查微信实际内容。

本次验证为离线回归、合成图片基准与打包 Demo 检查。真实微信发送由用户验收，性能优化不代表能消除网络上传等待或保证零失败。
