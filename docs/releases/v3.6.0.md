微信图片顺序发送助手 v3.6.0：蓝白桌面界面、原创 Logo，以及发送确认和任务恢复改进。

## 下载与运行

1. 下载下方 Assets 中的 `WeChatImageSender-3.6.0-Windows-x64.zip`。
2. 完整解压，保留 `WeChatImageSender.exe` 旁的 `_internal` 文件夹。
3. 双击 `WeChatImageSender.exe` 启动，无需安装 Python。

运行环境为 Windows 10/11 x64。Windows 7 指视觉风格。需要校验下载完整性时，可使用同名 `.zip.sha256` 文件。

## 本次更新

- 蓝白桌面工作台：Windows 7 风格的桌面层次，结合简洁排版，集中展示接收对象、队列与进度。
- 原创蓝白 Logo：照片叠层与发送箭头，应用到程序窗口、任务栏及 EXE 图标。
- 队列排序与实际发送顺序一致，自定义名称跟随图片；任务开始后锁定接收对象、顺序与名称。
- 扫描、预览和连接检查移到后台；只选择部分图片时，修改设置不会意外导入父文件夹中的其他图片。
- 提交结果不明时暂停并保留人工核实状态，避免盲目重发；改进 F8 停止响应和退出时的线程收尾。
- 新建或切换历史任务时清除旧核实截图，避免显示其他任务的证据。
- 增加 Windows 本地 OCR 文字确认，补齐打包所需的无障碍和 OCR 组件；截图不上传云端识别服务。
- 整理源码、使用说明和构建流程，独立脚本按需导出，发行包附 SHA256 校验文件。

## 验证范围

80 项离线回归测试、演示队列和 GitHub Windows 构建通过。本地打包 EXE 的演示队列、诊断、界面打开与正常退出，以及图标和依赖检查通过。

已在当前电脑的深色微信、125% 显示缩放下，向自己的文件传输助手实发两张人工样张及对应名称。图片画面匹配通过；名称识别曾触发暂停，调整本地 OCR 后通过只读复核，再人工标记完成，没有重发。整批无人干预发送及其他微信环境仍待进一步验证。

程序核实的是本地客户端状态，不能据此判断接收方已经收到或阅读。部分微信界面依赖 Windows 已安装的 OCR 语言组件；无法可靠识别时会暂停，请按界面提示核实。
