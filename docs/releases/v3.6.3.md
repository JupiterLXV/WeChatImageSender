# WeChatImageSender v3.6.3

修复 3.6.2 遇到历史同图就直接暂停的问题。

- 允许重复发送同一图片，跟踪最新的右侧图片及本轮上传状态；上方已完成的旧图不会代替本张图片确认。
- 保留转圈消失后的连续稳定检查，以及名称发送前的再次检查。
- 保留手动点击微信聊天后“刷新/定位聊天”的流程、蓝白界面与 Logo。

下载 Windows x64 ZIP，完整解压后运行 `WeChatImageSender.exe`，保留 `_internal` 等配套文件，无需安装 Python。

旧版已暂停的条目如果图片已经完成上传，请核实后选择“仅补发名称”，避免重发图片。

本次使用合成图片、模拟窗口与离线演示验证；真实微信发送由用户验收。
