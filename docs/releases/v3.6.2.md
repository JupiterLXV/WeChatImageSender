# WeChatImageSender v3.6.2

修复图片仍在转圈时名称先发出的问题，并加强不同显示环境下的判定。

- 转圈暂时不动也不会视为完成；图片匹配、转圈消失且连续稳定至少 1.5 秒后才继续，名称提交前再次检查。
- 按显示缩放和窗口客户区识别消息区，排除输入框预览；窗口、布局或截图方式变化时暂停核实。
- 粘贴操作发生异常后不重复整套按键；旧版未完成的确认记录恢复时重新核实。
- 保留手动点击微信聊天后“刷新/定位聊天”的流程、蓝白界面与 Logo。

下载 Windows x64 ZIP，完整解压后运行文件夹内 `WeChatImageSender.exe`，目标电脑无需安装 Python。请保留 `_internal` 等配套文件。

已经过离线回归及模拟演示；真实微信发送由用户验收。若图片仍在转圈，请继续等待，勿手动提前补发名称。
