# WeChatImageSender v3.6.6

针对图片发出后到图片名称之间的等待，减少大图重复识别计算和叠加的固定等待。

- 动态聊天画面使定位缓存失效时，仍可复用缩略图及中心圈对照模板，避免每帧重复转换、缩放完整大图。
- 发送保护期与稳定观察同时计时，粘贴等待仅执行一次。
- 保留转圈、失败标记拦截、至少 1.5 秒和四帧稳定确认、名称前复查及 F8 暂停。
- 保留现有蓝白界面、Logo 和手动刷新定位聊天流程。

完整解压 Windows x64 ZIP，运行文件夹内 `WeChatImageSender.exe`，无需安装 Python。旧版本和历史任务可保留。

本版使用合成图片、模拟窗口和离线 Demo 验证；真实微信发送由用户验收。分析耗时下降不等于网络上传速度提升，也不保证所有环境下相同的图名间隔。
