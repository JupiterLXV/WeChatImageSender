修复 v3.6.0 接收对象定位不可用的问题，恢复原版手动定位与发送算法，保留蓝白界面和 Logo。

## 下载

下载下方 Assets 中的 `WeChatImageSender-3.6.1-Windows-x64.zip`，完整解压后运行 `WeChatImageSender.exe`，保留旁边的 `_internal` 文件夹。无需安装 Python，运行环境为 Windows 10/11 x64。

同名 `.zip.sha256` 文件用于校验下载完整性。

## 这次修复

- 恢复原版微信窗口定位、图片确认和名称提交算法。
- 操作改回：先在微信中手动点击目标聊天，再回程序点击“刷新/定位聊天”。
- 无法读取具体昵称时，允许使用“当前微信聊天”，不再强制通过 OCR 或精确名称识别才能发送。
- 后台检查只更新连接状态，不代选联系人或覆盖手动定位结果；手动刷新遇到后台检查时会排队执行。
- 保留蓝白界面、原创 Logo、队列排序、任务记录和异常恢复。
- 源码启动脚本优先运行当前源码，避免误启动旧版 EXE。
- 发行附件仅保留完整 Windows 程序包与 SHA256 校验文件。

## 使用方式与验证范围

1. 在微信中手动打开需要发送图片的聊天。
2. 回程序点击“刷新/定位聊天”，检查你在微信中打开的接收对象。
3. 导入图片并检查顺序、名称和发送快捷键，再开始发送。

本版只进行离线回归、模拟队列和打包检查，没有进行真实微信发送验证。实际发送测试由用户完成。
